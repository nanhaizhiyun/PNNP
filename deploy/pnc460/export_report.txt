PNC460 去噪模型 (PNC460_on_CombGT_Kcal_Unet_best_model.pth) -> TFLite
========================================================
参数量: 7,760,484
输入: (1, 512, 512, 4) float32, NHWC, 值域 [0,1]（4 = packed Bayer R/Gr/B/Gb）
输出: (1, 512, 512, 4) float32
权重迁移校验: PyTorch vs Keras 最大误差 4.77e-07

文件                     大小      与 fp32 一致性(真实数据)   说明
unet_512_fp32.tflite   31.06 MB   PSNR 120 dB（逐位一致）     基准
unet_512_fp16.tflite   15.55 MB   PSNR 86.6 dB（无损）       ★ 推荐默认
unet_512_dyn.tflite     7.83 MB   PSNR 48.9 dB              int8 权重 + float 激活
unet_512_int8.tflite    7.88 MB   PSNR 31.9 dB（max diff 0.21） 仅 NPU 强制要求时用

说明:
- fp16 在手机上由 GPU/NPU 原生支持，速度与精度都最优，作为默认部署版本。
- 全 int8 误差偏大（激活量化 per-tensor），若设备 NPU 只吃 int8，
  建议做 QAT 或改进校准后再用。
- 本机 CPU 计时（~1.1s/512x512）不代表手机性能，需真机 benchmark。

推理前处理（必须与训练一致）:
  1. raw (uint16) -> packed Bayer (4,h,w):  (r,g1,b,g2) 按 2x2 取样
  2. x = (packed - bl) / (wp - bl)            bl=64, wp=1023
  3. x = clip(x * ratio, 0, 1)                 ratio 由场景亮度决定（暗场景 40-80）
  4. 高光软削顶: x>0.75 处 x = 0.75 + 0.22*tanh((x-0.75)/0.22)
  5. 转 NHWC 后送入模型
后处理: 输出 (4,S,S) -> 去马赛克 -> 白平衡 -> 色调映射 -> 色度抑制（见 scripts/inference_pnc460.py）
分块: 512x512 无重叠即可（网络感受野有限），块间交界可按 32px 重叠平均
