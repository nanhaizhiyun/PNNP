PNC460 去噪模型 -> TFLite
模型: PNC460_on_CombGT_Kcal_Unet_best_model.pth (7,760,484 参数)
转换方式: Keras 同构重建 + 逐层权重迁移（PyTorch-Keras 最大误差 4.77e-07）
接口: 输入 (1,H,W,4) float32 NHWC [0,1]；输出 (1,H,W,4) float32
      4 通道 = packed Bayer (R, Gr, B, Gb)

=== 512x512 分块版（推荐移动端，内存友好）===
unet_512_fp32.tflite     31.06 MB   PSNR 120.00 dB（逐位一致）
unet_512_fp16.tflite     15.55 MB   PSNR  86.55 dB（无损）   ★
unet_512_dyn.tflite       7.83 MB   PSNR  48.86 dB  (int8 权重 + float 激活)
unet_512_int8.tflite      7.88 MB   PSNR  31.93 dB  (全整数量化，精度不足)

=== 1536x2048 整幅版（= 3072x4096 raw 的 packed 尺寸，一次推理）===
unet_1536x2048_fp32.tflite  31.06 MB   逐位一致
unet_1536x2048_fp16.tflite  15.55 MB   PSNR 87.33 dB（无损）   ★
unet_1536x2048_int8.tflite   7.88 MB   PSNR 33.04 dB (max diff 0.36，不建议)

（一致性为真实 raw_snap 帧上与 PyTorch 模型的对比）

=== 工程注意事项 ===
内存: 整幅 1536x2048 第一层卷积输出即 32×1536×2048 ≈ 400 MB，
      峰值估计 1.5-2 GB。手机 App 可能 OOM —— 若 OOM 改用 512 分块
      （12 块，块间 32px 重叠平均）。
速度: 本机 CPU 13-16 s/帧，不代表手机；GPU delegate + fp16 预计 2-5 s/帧。
int8: 激活为 per-tensor 量化，误差偏大（max 0.36）。若设备 NPU 强制 int8，
      需做量化感知训练（QAT）或改用更细粒度校准。

前处理（必须与训练一致）:
  1. raw (uint16) -> packed Bayer (4,h,w)
  2. x = (packed - 64) / (1023 - 64)
  3. x = clip(x * ratio, 0, 1)        暗场景 ratio 40-80
  4. 高光软削顶: x>0.75 处 x = 0.75 + 0.22*tanh((x-0.75)/0.22)
  5. 转 NHWC
后处理: 输出 (4,H,W) -> demosaic -> 白平衡 -> gamma/色调映射 -> 色度抑制
        （完整参考实现见 scripts/inference_pnc460.py）
